# Documentation

Design and decision documents for "Discover the Cosmos", a space-themed AI agent. Start with the architecture overview, then the decision records.

| Folder | What is in it |
|---|---|
| [`architecture/space-agent-architecture.md`](architecture/space-agent-architecture.md) | The architecture overview (goals, building blocks, runtime, deployment, decisions index). Start here. |
| [`architecture/app/`](architecture/app/) | Components view and decision records (ADRs 0001–0013) for this repo. |
| [`architecture/mcp/`](architecture/mcp/) | Components view and ADRs for the MCP server repo. Kept here because the decisions span repos. |
| [`architecture/index/`](architecture/index/) | Components view and ADR for the (private) index repo. |
| [`ui/`](ui/README.md) | One specification per screen, plus shared conventions. |
| [`business/`](business/) | Product requirements, the fixed on-screen texts, the About screen content and the two illustration specifications. |

## Screenshots

The UI specs refer to design boards. Screenshots of those boards are kept locally and are not part of this repository.

## Decision records

Decision records are numbered per repository in the order they were decided and are never renumbered. A decision that was replaced stays in place with its status changed.
